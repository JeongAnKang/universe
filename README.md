# 여섯 등급에서 우주까지

히파르코스의 별 밝기 등급에서 오늘날의 우주론까지, 사람이 별의 **밝기·거리·온도**를 재고 **관측 도구**를 발전시키며 우주관을 넓혀 온 과정을 따라가는 학습 웹입니다.

## 구성
- **1막 맨눈으로 하늘을 기록하다** (BC 2세기–1609) · 실험 1: 등급 비교
- **2막 망원경, 6등급 너머를 보다** (1609–1800) · 실험 2: 망원경 구경과 집광력
- **3막 빛을 쪼개고, 별까지 거리를 재다** (1800–1913) · 실험 3: 연주 시차·절대 등급 / 실험 4: 별의 색과 온도
- **4막 성운이 은하가 되다** (1912–1930) · 실험 5: 허블 법칙
- **5막 보이지 않는 빛으로 본 우주** (1930–현재) · 실험 6: 빛의 창(대기와 망원경 위치)
- 확인 퀴즈 8문항

## 파일
```
index.html      페이지 구조
css/style.css   스타일 (라이트/다크 테마)
js/main.js      연표 데이터, 실험실, 퀴즈
```

## 실행
별도 설치 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages(Settings → Pages → main 브랜치)로 배포할 수 있습니다.
